# CrewPlacement Agent Rules

- Все исходные файлы и пользовательский текст должны оставаться в UTF-8 без повреждения кириллицы.
- Сохраняйте мобильный сценарий равноправным десктопному: элементы управления должны работать от ширины 320 px без горизонтальной прокрутки.
- Не отключайте серверные проверки ролей, CSRF-защиту и запрет двойного назначения сотрудника в одну дату и смену.
- Не помещайте пароли и `SECRET_KEY` в репозиторий. Рабочие значения задаются только через `.env` или переменные окружения.
- Не изменяйте существующую базу данных или справочники массово без резервной копии и явного запроса пользователя.
- После изменений запускайте `python -m unittest discover -s tests -v`, `python tools/check_utf8.py` и `docker compose build` для изменений упаковки.
